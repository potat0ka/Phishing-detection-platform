Upgrade the phishing detection platform by implementing a full role-based access control (RBAC) system using Python (Flask) and MongoDB.

Define 3 roles: Super Admin, Admin, and User — each with specific access levels and dashboard features.

---

1. Super Admin (Platform Owner):
   - Has full access to the platform and all dashboards.
   - Can add or remove users and admins.
   - Can promote users to admin and demote admins to users.
   - Can change the password of any user or admin, but only if the user has requested it from their dashboard.
   - Can upload and update machine learning models, safety tips (email, URL, general), and any platform modules from their dashboard.
   - Can view global statistics, audit logs, and manage all scans and user data.
   - Cannot be demoted or deleted by anyone.

2. Admin:
   - Can add or remove users only.
   - Can change the password of users upon request.
   - Cannot manage Super Admins or promote/demote anyone.
   - Can upload and manage safety tips and improved models via their dashboard.
   - Can moderate user reports and view limited stats (not global).

3. User:
   - Can access only their own dashboard.
   - Can submit phishing checks (URL, email, text).
   - Can view their own scan history and analysis results.
   - Can view safety tips.
   - Can request a password reset (which will be handled by Admin/Super Admin).
   - Cannot manage any users or models.

---

System requirements:
- Store role in the user collection in MongoDB (`role: "user"`, `"admin"`, `"superadmin"`).
- Use decorators or middleware in Flask to protect routes and dashboard views based on roles.
- Make all role-specific actions and dashboards clearly separated and secure.
- Use modular Flask structure and clearly comment each file and route for maintainability.
- Ensure dashboards display only allowed options for the logged-in user's role.
- Add backend logic to support password reset requests and allow Super Admin/Admin to change passwords upon request.
- Allow Super Admin and Admin to upload new ML models and safety tips via dashboard, save them securely, and use them dynamically in analysis.

Make sure each role has its intended access only and cannot bypass restrictions from the frontend.

Use Python and MongoDB. Keep it clean, secure, and beginner-friendly.
